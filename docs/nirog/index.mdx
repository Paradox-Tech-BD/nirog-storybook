# Nirog Documentation

Nirog documentation is currently at the end of its **general pre-analysis** phase. The completed analysis corpus has been grouped in [`pre-analysis/`](./pre-analysis/). The native Storybook presentation lives in [`preview/`](./preview/), while its source-controlled documentation pages are visible through the published Storybook instance.

## Current status

The product boundary, ML evidence rules, user/profile authority model, catalog distinction, regimen activation boundary, logical schemas, API baseline, and subsystem interactions are documented and coherent at the general-analysis level. Technical analysis has **not** started; it will begin only on an explicit product-owner instruction.

## Technical-analysis boundary

When authorized, implementation-level artifacts will be added under `docs/nirog/technical-analysis/`. They will specify runtime/deployment, backend modules, physical persistence, API implementation, ML worker engineering, Flutter integration, and security/operations mechanics while preserving the pre-analysis product decisions unless they are explicitly changed.
