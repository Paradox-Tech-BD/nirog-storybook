# Nirog Backend Documentation

This section is the canonical home for Nirog documentation within the Storybook fork. It contains a cohesive backend blueprint for the Flutter-to-ML prescription workflow, together with implementation contracts, data schemas, architecture decisions, source references, and operational requirements.

> **Primary document:** [Nirog Backend Blueprint](./backend-blueprint.mdx). It is written so it can be copied directly into Notion. The standard Mermaid blocks render as flowcharts, sequence diagrams, state diagrams, and ER diagrams when pasted into a Notion Mermaid block.

## Maintenance rule

When a change affects API fields, schemas, ML stages, release artifacts, catalog behavior, or user-visible documentation, update the blueprint and the related source contract in the same pull request. Future Nirog documentation changes are made in this section of the fork.
