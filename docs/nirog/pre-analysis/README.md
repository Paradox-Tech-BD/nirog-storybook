# Nirog General Pre-Analysis

This directory groups all Nirog work completed before technical analysis: requirements, safety boundaries, research, architecture hypotheses, logical schemas, API baseline, subsystem interactions, and conceptual decisions.

Read [`final-coherence-check.md`](./final-coherence-check.md) before beginning any future technical-analysis work. The technical phase is intentionally paused until the product owner asks to begin it.

The interactive native Storybook presentation is also part of this bundle under [`storybook/`](./storybook/). Its Netlify deployment configuration is maintained at the repository root because Netlify reads `netlify.toml` before choosing this folder as the build base.
