# ML Integration Pre-Analysis

This directory contains product-level guidance for connecting Nirog’s prescription evidence workflow to an ML pipeline. It records the accepted behavioral boundary, source inputs, and handoff conditions without choosing the final worker topology, model host, queue, vector database, or deployment platform.

Start with [`notion-ml-integration-guide.md`](./notion-ml-integration-guide.md). The existing [`../architecture/ml-pipeline-contract.md`](../architecture/ml-pipeline-contract.md) remains the canonical pipeline behavior contract.
