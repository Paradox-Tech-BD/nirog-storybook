# Reference Catalog and Data Quality

The Medicine Catalog is shared reference data with source provenance, curation, immutable release manifests, quality rules, and release-bound search/matching indexes. A correction produces a reviewed successor release. It does not silently rewrite a historic release that influenced a prescription review.

<MermaidDiagram title="Curated catalog release lifecycle" chart={catalogRelease} />

Private user corrections can support the current review experience, but they do not automatically change shared reference data. Promotion requires a curation case, source evidence, review decision, new release, index validation, and rollback path.
