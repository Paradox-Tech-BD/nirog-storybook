# Canonical Records and Lineage

This page distinguishes authoritative records from derivatives and preserves the provenance chain that explains a result. Original assets, stage manifests, user-confirmed actions, catalog releases, and audit/control records are governed sources. Search indexes, schedule projections, summaries, cache entries, and synchronized mobile representations are disposable derivatives with explicit rebuild inputs.

<MermaidDiagram title="Evidence-to-action lineage is directional" chart={lineageFlow} />

Lineage records source entity, activity, agent, version, policy/release, and input fingerprint. Audit records a separate question: who attempted or performed which policy-governed access or action. The distinction ensures the backend can explain both the origin of a reviewed candidate and the decision that created a regimen.
