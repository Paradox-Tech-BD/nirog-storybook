# Regimen, Adherence, and Mobile Sync

Regimen versions, dose events, and inventory adjustments are user-confirmed or user-recorded canonical actions. Notification delivery is not proof that a dose was taken, and an OCR candidate is not a regimen. Future schedule occurrences, adherence summaries, and mobile deltas are rebuildable projections tied to source aggregate and policy versions.

<MermaidDiagram title="Offline intent and authorized mobile sync" chart={syncFlow} />

Flutter holds a protected, profile-authorized cache and an offline intent outbox. The server resolves authorization, idempotency, base-version conflicts, and cursor scope. It sends resource-version deltas—not raw restricted objects or generic table replication.
