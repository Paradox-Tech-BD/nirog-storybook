# Access, Scalar, and Workers

Fastify and TypeBox validate the transport contract; they do not replace Nirog’s full command-validation and authorization pipeline. Each command then resolves a local OIDC actor, persisted RBAC permission snapshot, exact profile/resource relation, consent/purpose, state/version, idempotency, and database constraints.

## Scalar as the live developer reference

The same Fastify route schemas generate `/openapi.json` and a Scalar reference at `/reference`. OpenAPI snapshots are linted and compared in CI; generated Flutter clients consume a reviewed API release rather than hand-maintained models. Internal worker operations are excluded from the public reference or served through a distinct restricted specification.

## Worker and RAG safety

The outbox dispatcher publishes only committed events. Python consumers use a consumer ledger for duplicate safety, re-check current state, and invoke restricted internal Core commands. OCR output and RAG results are evidence or assistance. They cannot mutate regimen/adherence state or make medication decisions.

Retrieval begins with approved catalog and governed knowledge material in PostgreSQL/pgvector. Patient-specific RAG is deferred pending its own consent, retention, redaction, source-admission, and safety decision.
