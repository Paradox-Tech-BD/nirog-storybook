# Quality, Delivery, Operations, and Documentation

Nirog’s operational baseline combines local Docker Compose profiles, strict code and contract checks, real-service integration testing, scanned container delivery, infrastructure as code, and redacted telemetry. A release is not ready because an endpoint runs; it must prove authorization, data, asynchronous, contract, and recovery safeguards.

<MermaidDiagram title="Nirog quality and delivery pipeline" chart={deliveryMap} />

## Required controls

**Quality gates.** Ruff, Pyright strict, pytest, Hypothesis, Testcontainers, Schemathesis, Redocly, Semgrep, Gitleaks, pip-audit, and Trivy jointly protect code shape, types, database/RLS behavior, API contract, secrets, dependencies, and images.

**Delivery profile.** GitHub Actions produces scanned Docker images and OpenTofu plans. ECS Fargate hosts independently scaled API, relay, and worker classes; RDS, managed Valkey, S3/KMS, Secrets Manager, WAF, and IAM workload roles form the production baseline.

**Documentation.** Storybook MDX and Mermaid remain the human-reviewed architecture source. FastAPI OpenAPI is the executable interface source. Redocly validates the contract and generates reference material; ADRs record consequential implementation decisions.
