# Interactions and Events

The system uses the smallest integration style that keeps ownership clear. Low-latency authorization and catalog search use queries. A change to another subsystem’s data uses a command. A consequence that can happen asynchronously uses an outbox event.

<MermaidDiagram title="Subsystem interaction contract map" chart={integrationFlow} />

## Core commands

`CreateScanJob` belongs to Prescription and ML Evidence. `RecordMedicationReview` belongs to the same subsystem. `CreateRegimenFromReview` belongs to Medication Regimen. `RecordDoseLog` and `RecordRefill` belong to Adherence and Notifications. `CreatePatientProfile`, `GrantProfileAccess`, and `RevokeProfileAccess` belong to User Management.

## Core events

`RegimenVersionActivated` and `RefillRuleChanged` let the Adherence subsystem refresh reminder behavior. `DoseLogged` and `RefillRecorded` let the Regimen subsystem update inventory projections. Every important command also emits an audit action and profile-scoped sync change through the platform subsystem.
