# Medicine Catalog

The catalog is shared reference data. It stores released medicine identity, not a patient’s personal schedule, stock count, or adherence. The patient-selectable record is **MedicineProduct**, linked to generic ingredients, manufacturer, dosage form, aliases, and source release.

<MermaidDiagram title="Medicine catalog class model" chart={catalogModel} />

## Release rule

Every product fact is attached to a `CatalogRelease` with source provenance. OCR matching also references a `MatchIndexRelease`, so the same prescription can be explained against the exact catalog and embedding index that were active when it was processed.

## What other subsystems receive

Prescription and ML Evidence sends normalized extracted text to the catalog search contract and receives ranked candidates. Medication Regimen stores a `medicine_product_id` as an identity reference but never mutates catalog product facts.
