# Nirog Backend Blueprint

This is the complete native Storybook documentation experience for the Nirog backend. The sidebar contains the architecture, subsystem boundaries, schemas, API contract, interactions, and class diagrams that are also preserved as Notion-ready source documents in this fork.

## Core product boundary

Nirog turns a user-provided prescription into **reviewable evidence**. It does not allow an OCR result to silently create an active medication schedule. A patient profile receives a medication regimen only after an authorised user confirms the medicine identity and instruction.

## What the backend owns

The backend protects profile-scoped health data, stores prescription evidence, runs asynchronous ML extraction, resolves candidate products from a released Bangladesh medicine catalog, versions confirmed medication instructions, produces schedule rules, records adherence events, and maintains a traceable audit history.
