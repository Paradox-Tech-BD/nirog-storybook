# General Pre-Analysis Handoff

The Storybook pages currently present the completed **general pre-analysis**. They establish the intended product behavior and conceptual constraints. They do not constitute an implementation-ready technical design, and the technical-analysis phase has not started.

<MermaidDiagram title="Nirog pre-analysis to technical-analysis boundary" chart={phaseBoundary} />

## What is complete

The pre-analysis has settled the safety boundary, profile and caregiver authority model, prescription-as-evidence rule, catalog/regimen distinction, explicit confirmation step, versioning expectations, notification/adherence separation, subsystem ownership, logical ER model, proposed API shapes, and ML provenance requirements.

## What is intentionally deferred

Technical analysis will later make implementation decisions about the runtime, storage, queue, workers, physical PostgreSQL schema, API middleware, object-storage controls, synchronization implementation, mobile integration, observability, and production release operations. It will begin only when the product owner requests it.
