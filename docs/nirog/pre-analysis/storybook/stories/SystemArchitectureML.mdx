# Prescription Evidence and ML Architecture

The ML pipeline transforms a restricted document into reviewable evidence. Every stage is tied to a manifest/fingerprint and configuration releases. It can preselect a candidate or route to manual entry, but it cannot create a medication plan. The evidence-assisted review command invokes the Regimen module only after current authority, evidence version, catalog release, policy, edited fields, and idempotency validate.

<MermaidDiagram title="Evidence-first ML and explicit medication-action boundary" chart={evidenceFlow} />

Raw OCR/crops/provider outputs remain restricted assets. Queue and telemetry payloads use identifiers, checksums, error class, duration, and release references. A material model, prompt, parser, catalog/index, or policy change creates new lineage and evaluation/rollout evidence.
