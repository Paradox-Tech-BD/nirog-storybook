# Security, Privacy, and Governance Architecture

Security is layered. OIDC authenticates an account actor; Nirog evaluates profile authority independently; owner repositories and RLS constrain records; workload identity constrains workers; private asset capability limits storage; typed adapters control egress; and audit/provenance record sensitive actions without duplicating health content.

<MermaidDiagram title="Layered authority, storage, worker, and egress controls" chart={securityLayers} />

No token, profile ID, team membership, object UUID, or queue message grants health-data authority by itself. Release artifacts—model, prompt/parser, catalog/index, policy, feature, evaluation, retention, migration—are versioned governance records with owner, approval, compatibility, rollout, and rollback/compensation evidence.
