# Technical ML Evidence and Safety

The technical ML architecture treats every inference as evidence. The source document, preprocessing derivative, OCR lines, extracted fields, ranked catalog candidates, policy result, and user decision remain linked through immutable, versioned records.

<MermaidDiagram title="The only path from ML evidence to a regimen" chart={mlSafetyBoundary} />

## Non-negotiable enforcement

ML workers receive stage references, not user tokens or broad profile data. They write stage-run results inside the Prescription/ML Evidence boundary. They cannot write regimen, schedule, inventory, reminder, or notification tables. The sole regimen path is an authenticated review command that validates evidence version, profile permission, catalog release, edited values, and idempotency.

Confidence is a policy input that routes to review, manual entry, or failure. It is never a treatment-activation state.
