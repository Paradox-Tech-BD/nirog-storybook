# Platform, Security, and Operations

The platform architecture provides versioned API contracts, idempotent mutation, optimistic concurrency, row-level defense, audit, change feed, feature flags, retention jobs, observability, backups, and controlled deployment promotion.

<MermaidDiagram title="Production runtime topology" chart={operationsTopology} />

## Operational posture

Nirog separates development, staging, and production. Production uses stateless API replicas, private object storage, managed PostgreSQL, scoped service identities, queue-isolated worker pools, secret management, encrypted backups, and trace/metric/log telemetry that excludes raw prescription content.

ML, parser, catalog, index, and review-policy changes are independently versioned release artifacts with evaluation and rollback paths. A costly ML outage must degrade to retry or manual entry without blocking essential medication records.
