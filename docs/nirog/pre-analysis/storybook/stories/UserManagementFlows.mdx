# User Management Interaction Flows

User Management is the authority boundary, not merely login storage. It determines which profiles the actor can see and which fields/actions they may access for every request. A patient profile can be the account owner’s own context or a dependent’s context; an account never acquires healthcare-data access merely by knowing a profile ID.

## Interaction contract

User Management publishes an effective permission decision, profile status, device settings, and user timezone. Prescription, regimen, adherence, and sync modules call the policy contract before loading profile-scoped data. They do not copy profile memberships or make authorization decisions from a client-provided account ID.

Membership can be revoked without deleting the profile. A raw-image permission is narrower than a general caregiver role, and consent for sharing remains distinct from optional research consent.
