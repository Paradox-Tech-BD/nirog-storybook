# Dose, Refill, Offline Sync, and Reminder Delivery

Schedule policy, planned occurrence, notification delivery, user dose event, inventory adjustment, and adherence summary are separate artifacts. A notification delivery/open does not prove a dose; a user’s taken/skipped/correction command is the canonical adherence event. Flutter retains protected local intent and a scoped view while the server resolves authorization, idempotency, conflict, and current state.

<MermaidDiagram title="Offline intent, canonical dose event, and derived mobile updates" chart={mobileDoseFlow} />

Future schedule occurrences and summaries are rebuildable. Refill/inventory uses a controlled event ledger; notification providers use deterministic intents and reconciliation before resend. Time zone/DST, stopped regimen, revoked device, duplicate offline submission, and provider uncertainty are all explicit workflow branches.
