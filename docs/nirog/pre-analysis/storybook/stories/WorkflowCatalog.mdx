# Catalog Source, Release, and Match Context

The catalog workflow makes shared medicine facts accountable and reproducible. It validates source provenance, creates curation cases, publishes immutable successor releases, and builds release-bound search/match indexes. Historic review uses the release/index/policy context recorded at the time, even after a newer catalog release becomes active.

<MermaidDiagram title="Curated catalog source-to-release workflow" chart={catalogWorkflow} />

A search result or ML candidate is reference context only. Strength, form, route, and ingredient compatibility filter candidates before ranking; ambiguous/no-compatible results route to review or manual entry, not forced mapping.
