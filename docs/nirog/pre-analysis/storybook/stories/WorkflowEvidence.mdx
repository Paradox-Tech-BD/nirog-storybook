# Restricted Upload, ML Evidence, and Review

Prescription ingest creates a narrow upload grant, verifies checksum/object policy, records an immutable asset manifest, and commits a scan request. Workers then run pre-processing, recognition, structured extraction, release-bound matching, and review-policy evaluation with stage manifests and source lineage.

<MermaidDiagram title="Evidence lifecycle from upload to user review" chart={evidenceWorkflow} />

The complete workflow intentionally has no automatic regimen-activation state. ML/model/provider output is evidence. The only path beyond a review payload is a new, authorized Regimen command made by the user or permitted delegate.

Read [Upload and Ingest](https://github.com/Paradox-Tech-BD/nirog-storybook/blob/main/docs/nirog/design-workflows/03-prescription-evidence/01-upload-and-ingest.md) and [Stage Processing and Review](https://github.com/Paradox-Tech-BD/nirog-storybook/blob/main/docs/nirog/design-workflows/03-prescription-evidence/02-stage-processing-and-review.md).
