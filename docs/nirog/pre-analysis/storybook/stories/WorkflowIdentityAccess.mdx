# Account, Profile, Sharing, and Consent

OIDC proves account identity, while Nirog computes local profile authority. Each profile action re-evaluates ownership or caregiver grant, permission, validity window, consent/purpose, resource relationship, and account/device state. A valid login alone never authorizes a medication action for every profile.

<MermaidDiagram title="Current profile capability before every scoped action" chart={profileGate} />

Caregiver grants use a proposed → pending → active → suspended/revoked/expired lifecycle. Revocation takes effect for new reads/writes immediately and causes dependent queued sensitive work to cancel or no-op after its worker recheck.
