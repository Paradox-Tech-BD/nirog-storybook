# Confirmation to Versioned Regimen

The Regimen module is the only owner that turns an explicit confirmation or manual entry into a medication plan. It validates current profile authority, review payload state/expiry when used, catalog/reference compatibility, aggregate concurrency, and idempotency before it writes a new versioned regimen.

<MermaidDiagram title="Evidence-assisted confirmation becomes a separate regimen command" chart={confirmationFlow} />

Later edits, pauses, resumes, and stops create controlled successor/current states rather than mutating history. Schedule and notification work begins only from committed `regimen.changed`/`schedule.changed` events; projectors cannot rewrite the canonical regimen.
