# Medicine Subsystem Interaction Flows

The Medicine Catalog subsystem owns released reference facts: products, ingredients, manufacturers, forms, aliases, catalog sources, and matching-index releases. It does not own an individual’s regimen or supply count. Prescription and ML Evidence uses the catalog for candidates; Medication Regimen stores only an approved product reference or private unresolved medication.

## Interaction contract

The catalog query accepts normalized evidence, release context, optional strength, dosage form, and route hints. It returns ranked candidates with product identity, verification status, and release provenance. The scan subsystem stores candidate scores as evidence, not as an accepted medicine fact. A user review selects the match before Medication Regimen can create a personal course.

Shared aliases, transliterations, and product changes must pass curation and publication. A newly published catalog release and its match-index release apply to future jobs; historical scan results retain the named release they used.
