# User Management

This subsystem is the permission boundary for all profile-scoped health information. A **User** is an authenticated application account. A **PatientProfile** is the medication-management context for the owner or dependent. The two must not be treated as the same record.

<MermaidDiagram title="User management class model" chart={userModel} />

## Ownership

User Management owns `users`, `auth_providers`, `user_preferences`, `devices`, `patient_profiles`, `teams`, `team_members`, `team_invitations`, `profile_access`, and `consent_records`.

## Permission rule

Team membership is not automatic patient access. Every document, scan, regimen, dose log, and notification request checks an effective `ProfileAccess` grant for the requested patient profile. The grant is explicit, role-based, revocable, and audited.

## Integration outputs

Other subsystems receive a profile identifier and a resolved permission decision; they do not duplicate identity rows. User Management also provides timezone and device-preference snapshots used by reminder delivery.
